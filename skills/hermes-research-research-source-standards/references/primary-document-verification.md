# Verifying a Primary Document Behind an Outline

> Use when a brief, outline, or daily data file summarizes a document you are about to write from: a government advisory, a vendor threat report, an arXiv paper, a funding filing.

## Why the summary is not enough

The summary exists to tell you the story exists. It compresses the noun, the unit, and the scale, and the compressed version reads perfectly plausible while being wrong. You cannot spot-check a paraphrase, and neither can the reader.

## Procedure

1. **Find the story** in the daily data file (IronPulse, TensorFeed, weekly report). Note the outlet it credits.
2. **Locate the primary document.** For a government advisory, search the issuing agency's own advisory index and the outlet coverage to get the document number. For a vendor report, fetch the vendor's news or research listing page and extract the canonical report URL from the raw HTML (the link may only exist there, as an absolute URL).
3. **Fetch the document and read the sections you will write from**, not the headline. Save the text once and slice by section heading.
4. **Check the noun, the unit, and the scale** against the outline line you planned to reuse. Write the document's version, not the outline's.
5. **Name the document in the deliverable**: number plus issuing bodies plus date.
6. **Attribute allegations as allegations.** "The agencies alleged" or "the company assesses," plus one plain sentence stating this is not an adjudicated finding. In the body, not a footnote.
7. **List only what the body cites** in references or SOURCES. Drop checked-but-unused entries; one unfindable entry discredits the rest.
8. **Report changes to the user** in one line each: outline said X, source says Y, why it matters.

## Paraphrase traps seen in practice

| Outline phrasing | What the primary source actually shows |
|---|---|
| "N platforms" | N software modules inside a single suite |
| "a funding round" | a share placement plus a convertible bond sale, disclosed separately |
| "the report said X" | X came from outlet coverage of the report, not the report |
| headline figure as typical case | the source's figure is a percentile or a peak |

## Pitfalls

- A summary's credited outlet is a lead, not the source. Go to the document.
- A data file with the story but no document number is a dead end for citation; find the number before writing the claim.
- When an outline item is real but does not support the argument, drop it from the body. Do not park it in references as a consolation prize, and do not force-fit it with a stretched connection.
