# Pi Coding Handoff Section — The System

## What It Is

The `FOR PI CODING ONLY` block at the bottom of article files is not notes, not garnish, not dead weight. It is a **deliberate working protocol** between Vinny and Pi — the operational handoff that makes the publishing pipeline work. Pi is a tool with its own input requirements; feed it wrong and you get garbage out. The block is tuned to how Pi parses, not how a human reads.

## Who Manages It

Vinny manages this section himself. He populates the keywords, sources, and instructions as part of his process. He does this deliberately because it forces him to read the article end to end and follow up — it's a management practice, not a gap to fill.

**Do not touch this section unless Vinny explicitly asks you to.** Do not add keyword research to it, do not reformat it, do not "improve" it. It is his system, and it stays consistent because the whole pipeline depends on it.

## The Framing

"Sticking to the systems we built" is the right way to describe it. Vinny and Pi have a consistent way of working together. Vinny and Hermes have a consistent way of working together. Both are deliberate protocols built and maintained for consistency. Neither is better or worse — they're different tools with different handoff requirements.

## Structure

```
----------FOR PI CODING ONLY------DO NOT INCLUDE INSIDE OF THE ARTICLE------------------------------------------------

KEYWORD RESEARCH

[Optional: tiered keyword breakdown with Trends means, critical window, unique angle, internal links]

Keywords

[comma-separated list of target keywords]

SOURCES

- [Publication]: "[Headline]" (Date) - [URL]
- [Publication]: "[Headline]" (Date) - [URL]
...
```

## Rules

- The dashed separator line is long and explicit: `----------FOR PI CODING ONLY------DO NOT INCLUDE INSIDE OF THE ARTICLE------------------------------------------------`
- "KEYWORD RESEARCH" header is in all caps
- "Keywords" header is plain, followed by a comma-separated list
- "SOURCES" header is in all caps
- Each source is a bullet with: Publication name, headline in quotes, date in parentheses, URL
- Sources include both external links and internal PhantomByte article references
- This section is NOT included in the published article — it's a handoff block for Pi

## When Keyword Research Is Requested

When Vinny asks for keyword research on an article, the research goes into the keyword research report (emailed separately) AND/OR into the FOR PI CODING block — but only if Vinny explicitly tells you to add it there. By default, the keyword research is a separate deliverable. The FOR PI CODING block is Vinny's domain.
