# AI Trust & Authentication Infrastructure, Fact-Check Reference
Last updated: 2026-05-03

## Verified Facts (citable)

- **C2PA / Content Credentials**
  - C2PA spec v2.3 launched Feb 9, 2026; v2.4 current.
  - Members: Adobe, Amazon, BBC, Google, Meta, Microsoft, OpenAI, Publicis, Sony, Truepic.
  - 6,000+ members/affiliates with live implementations (Feb 2026).
  - 500+ companies implementing. c2pa.org, contentcredentials.org.

- **EU AI Act**
  - Regulation (EU) 2024/1689 entered force Aug 1, 2024.
  - Transparency and labeling requirements for high-risk AI outputs confirmed.

- **FIDO Alliance Agentic Authentication**
  - Announced April 28, 2026.
  - Working Group co-chairs: CVS Health, Google, OpenAI. Vice-chairs: Amazon, Google, Okta.
  - Google contribution: Agent Payments Protocol (AP2).
  - Mastercard contribution: Verifiable Intent Framework.
  - Three focus areas: verifiable user instructions, agent authentication, trusted delegation for commerce.
  - fidoalliance.org/fido-alliance-to-develop-standards-for-trusted-ai-agent-interactions/

- **WebAuthn / Passkeys**
  - WebAuthn Level 3 = W3C Candidate Recommendation Snapshot, Jan 13, 2026.
  - FIDO 2024 survey: 53% enabled passkeys on at least 1 account; 22% on every possible account.
