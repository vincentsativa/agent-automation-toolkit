# Excluded Stories (HARD RULE)

Before including ANY story in a report, check against this list. Any story
matching an exclusion below MUST be skipped entirely, do not include it,
summarize it, or mention it.

## Current Exclusions

- **OpenAI rogue agent**, all variants, all framing
- **Hugging Face breach**, all variants
- **AI kill switch act stories**, all variants
- **Any AI agent containment breach stories**, all variants

If a headline references any of these, drop it. Do not substitute a related
angle for a variant of an excluded story.
