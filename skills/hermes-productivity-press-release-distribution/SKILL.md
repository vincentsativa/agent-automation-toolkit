# Press Release Distribution

Write, format, and distribute press releases to platforms like PRLog.org and other newswires.

## When to Use

- Announcing product launches, partnerships, funding, or major updates
- Generating backlinks and SEO value through press coverage
- Distributing company news to journalists and news aggregators
- Creating shareable announcement content for social media

## Press Release Structure

### Standard Format

```markdown
## Headline
**Clear, benefit-driven headline with key announcement**

## Subheading
*Supporting detail or quantifiable impact statement*

---

## Body

**[CITY, STATE], [DATE]**, [Company], [brief descriptor], today announced [main announcement].

### What's Included/Key Details
- Bullet point 1
- Bullet point 2
- Bullet point 3

### Why This Matters (Optional)
Quote from spokesperson: "Relevant quote about the announcement."

### Target Audience
Who this is for and why they should care.

### How to Access/Participate
Clear call-to-action with steps.

### About [Company]
Boilerplate company description (2-3 sentences).

### Media Contact
[NAME]
[TITLE]
[Company]
Email: [CONTACT EMAIL]
Website: [URL]
```

### Key Components

| Section | Purpose | Tips |
|---------|---------|------|
| Headline | Grab attention, summarize news | Keep under 100 chars, lead with benefit |
| Subheading | Add context or metrics | Include numbers if possible |
| Dateline | Establish location/timing | Use format: CITY, STATE, DATE |
| Lead paragraph | Who, what, when, where, why | Answer all 5 Ws in first 2-3 sentences |
| Body details | Supporting information | Use bullets for features/inclusions |
| Quotes | Human perspective, credibility | Attribute to the operator/exec/expert (never "founder" for Vinny Barreca, he is a systems builder) |
| Call-to-action | What reader should do next | Make it specific and easy |
| Boilerplate | Company background | Standard "About" paragraph |
| Contact info | Media inquiries | Include name, title, email, website |

## Platform-Specific Guidelines

### PRLog.org (Free Tier)

**URL**: https://www.prlog.org/submit-free-press-release.html

**Free Features**:
- ✓ Search engine optimized webpage
- ✓ Distribution to search engines
- ✓ RSS feeds and email alerts
- ✓ Social sharing widgets
- ✓ Press room hosting
- ✓ Analytics (views, clicks, search phrases)
- ✓ PDF/Print version
- ✓ Post-release editing
- ✓ Advance scheduling and pre-release sharing

**Submission Process**:
1. **Pre-work**, Before opening PRLog:
   - Research current site branding (navigate to the actual domain, check homepage headline, tagline, offerings)
   - Search session history for existing drafts, previous PRLog attempts, or related discussions
   - Search filesystem for prior press release drafts, credentials files, or brand/contact info
   - Determine if each domain needs its own release or one combined release (different brands → separate releases)
2. Create free account at PRLog (or login if credentials exist in filesystem)
3. Navigate to "Submit Free Press Release"
4. Fill in:
   - Headline and body text (see drafting guidance below)
   - Category: Technology / Software / Artificial Intelligence
   - Industry tags (select multiple)
   - Keywords/tags (10-15 relevant terms)
   - Location (city, state, country)
   - Company name and website
   - Contact email
5. Upload company logo (recommended)
6. Preview and submit

**Approval Time**: 1-24 hours typically

**Metadata to Prepare**:
```
Categories: Technology, Software, AI
Industries: Software Development, Artificial Intelligence, Open Source
Keywords: [product name], [technology], [use case], [benefit]
Location: Your city/state
Company: Your company name
Website: Your URL
Contact: Your email
```

### Multi-Brand Workflow (Different Domains, Separate Releases)

When the request covers multiple brands/domains (e.g., `phantom-byte.com` AND `vincentsativa.com`):

1. **Treat them as separate press releases**, each domain gets its own headline, angle, metadata, and submission
2. **Research each domain independently**, navigate to each site, note the unique value proposition, tagline, and offerings
3. **Draft distinct angles**, don't reuse the same skeleton; each brand's offering determines the news angle:
   - phantom-byte.com → AI infrastructure tutorials, cost optimization, sovereign AI
   - vincentsativa.com → practical AI tools, debugging resources, developer education
4. **Save drafts separately**, name them `prlog-press-release-draft-{domain}.md`
5. **Pre-fill all metadata**, no bracketed placeholders left behind. City, contact email, location, company name all resolved before user reviews
6. **Keep contact consistent**, if both brands share the same contact person, note this in the drafts

## Keyword/Tag Strategy

**Best Practices**:
- Include product/service names
- Add technology stack terms
- Include use cases and benefits
- Add industry verticals
- Include location if relevant locally
- Use both short-tail and long-tail terms

**Example Tags for AI Announcement**:
```
OpenClaw, Ollama, AI Agents, Local LLM, Self-Hosted AI, 
Hermes Agent, Autonomous Agents, AI Infrastructure, 
Cost Optimization, Open Source AI, Developer Tools, 
MLOps, Privacy, Sovereign AI, Machine Learning
```

## Distribution Checklist

### Before Publishing
- [ ] Fill all bracketed placeholders
- [ ] Verify company name and URL consistency
- [ ] Check quote attribution and accuracy
- [ ] Proofread for grammar and AP style
- [ ] Prepare company logo/image assets
- [ ] Select appropriate categories and tags

### After Publishing
- [ ] Share PR link on social media (Twitter, LinkedIn)
- [ ] Embed PR widget on company website
- [ ] Include in newsletter/email signature
- [ ] Share in relevant communities (Discord, Slack, Reddit)
- [ ] Submit to industry news aggregators
- [ ] Monitor analytics for views/clicks
- [ ] Respond to any media inquiries promptly

## Common Mistakes to Avoid

1. **Overly promotional language** - Keep tone journalistic, not salesy
2. **Missing contact info** - Always include media contact details
3. **Too long** - Aim for 400-800 words for most announcements
4. **No clear news hook** - Lead with what's new, not company history
5. **Generic quotes** - Use specific, attributable statements
6. **Forgetting call-to-action** - Tell readers what to do next
7. **Skipping proofreading** - Typos undermine credibility

### Partnership Announcement
```
**[Company A] and [Company B] Partner to [Joint Value Proposition]**

[DATE], [Company A], [descriptor], today announced a strategic 
partnership with [Company B] to [what the partnership enables].

The collaboration will [specific outcome/benefit for customers].
```

### Funding Announcement
```
**[Company] Raises $[X]M to [Use of Funds]**

[DATE], [Company], [descriptor], today announced it has raised 
$[X]M in [round type] funding led by [Investor], with participation 
from [other investors].

The company will use the funding to [specific plans].
```
