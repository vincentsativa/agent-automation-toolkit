Usage:
    python3 freespoke_finder.py --pairs "nail salons:new york" "plumbers:tampa" \
        -o out.csv --domains out_domains.txt
    python3 freespoke_finder.py --file pairs.txt -o out.csv --domains out_domains.txt

pairs.txt format, one per line:  <industry> | <city>
