# Provider DNS Value Format Reference

When documenting provider-specific DNS records in an implementation guide, use this format:

```
## [Provider Name] Setup

**Record type:** TXT or CNAME
**Name/Host:** [exact hostname]
**Value:** [exact value from provider]
**TTL:** [recommended TTL]

**Steps:**
1. Log in to [provider dashboard URL]
2. Navigate to [exact UI path]
3. Click [exact button name]
4. Copy the [value/selector] exactly as shown
5. Return to your DNS provider
6. Create the record with the values above
7. Save and verify

**Quirks:**
- [Any special notes, e.g., "Microsoft assigns a dynamic partition character"]
- [e.g., "Long keys may be split at 255 characters by some DNS providers"]
```

## Key Rules

1. **Never invent values.** If the provider generates a specific record (DKIM key, CNAME target), tell the reader to copy it from their provider's dashboard.
2. **Never use generic SPF records.** `v=spf1 include:google.com ~all` is wrong. The correct value is `v=spf1 include:_spf.google.com ~all` and the reader must verify against current provider docs.
3. **Always verify UI paths against current documentation.** Provider dashboards change. What was "Security > Email Authentication" last year may be "Policies & Threat Protection" today.
4. **Note when records are provider-generated vs. customer-created.** DKIM keys are generated by the email provider. DMARC records are created by the customer. SPF records may be partially automated.
5. **Include verification commands.** For DKIM: `dig selector._domainkey.yourdomain.com TXT +short`. For SPF: use the PhantomByte checker. For DMARC: `dig _dmarc.yourdomain.com TXT +short`.

## Common Provider Values (Verify Before Using)

| Provider | Record Type | Typical Name | Notes |
|----------|-------------|--------------|-------|
| Google Workspace | TXT | google._domainkey | Selector is usually "google" |
| Microsoft 365 | CNAME | selector1._domainkey | Dynamic partition character in target |
| Mailchimp | CNAME | k1._domainkey (varies) | Selector assigned by Mailchimp |
| SendGrid | CNAME | s1._domainkey (varifies) | Automated security manages records |
| Mailgun | TXT | mte1._domainkey (varies) | Check Mailgun dashboard |

**These examples are for format reference only. Always pull current values from the provider's official documentation.**
